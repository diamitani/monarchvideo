## Hermes Self-Improvement Loop
1. **Episodic Capture**: Every PAL compilation, pre-production suite, media selection, and conversational diff patch is logged in the ROSTR `ContextEngine` episodic store.
2. **Trace Critique & Reflection**: After studio runs or user edits, inspect what changed (e.g., tighter headlines, slower logo outro, higher-contrast typography, better camera pacing) and distill concrete `LessonLearned` entries.
3. **Autonomous Skill Synthesis**: Convert recurring creative patterns into reusable Markdown `SKILL.md` recipes with progressive disclosure metadata (tags, runtime applicability, trigger conditions).
4. **Human-Gated Promotion**: Synthesized skills enter `pending-review` status. Only after explicit creator approval are they promoted into pinned `ContextEngine` memory and persisted to Firestore—preventing autonomous prompt drift or self-evaluation bias.
